# Atlas Learning Group website

This folder is ready for GitHub Pages and the custom domain atlg-llc.com.

## Uploading to GitHub

1. Open the duh831/atlg-llc repository.
2. Keep a backup of the current repository before replacing files.
3. Replace the old website files with everything in this folder.
4. Confirm that CNAME remains in the top level of the repository.
5. Commit the changes to the main branch.
6. Allow GitHub Pages a few minutes to publish the update.

The scheduling and LinkedIn buttons are already linked.
